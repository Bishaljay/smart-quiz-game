# 🎯 Smart Quiz Game

A Python-based interactive quiz game developed as a final project for **Stanford Code in Place**. The application asks multiple-choice questions, provides instant feedback, tracks scores, and displays the final result at the end of the quiz.

## 📌 Features

* Multiple-choice quiz questions
* Instant feedback for each answer
* Score tracking system
* Percentage calculation
* Pass/Fail evaluation
* User-friendly terminal interface
* Beginner-friendly Python implementation

## 🚀 Technologies Used

* Python 3
* VS Code / Terminal

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/smart-quiz-game.git
```

2. Navigate to the project directory:

```bash
cd smart-quiz-game
```

3. Run the program:

```bash
python quiz_game.py
```

or

```bash
py quiz_game.py
```
